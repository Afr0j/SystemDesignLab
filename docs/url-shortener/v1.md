# URL Shortener V1

## Goal

Build a basic URL shortening service.

## Architecture

Browser

↓

Spring Boot

↓

MySQL

## Features

- Create Short URL
- Redirect URL
- Delete URL
- URL Statistics

## Current Limitations

- Single Server
- Single Database
- No Redis
- No Load Balancer
- No Message Queue
- No Monitoring

## Future Improvements

- Redis Cache
- Load Balancer
- Multiple Servers
- Rate Limiter
- Distributed ID Generator
- Monitoring Dashboard
